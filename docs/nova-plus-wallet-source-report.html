2. Executive summary

108Imported mesh tokens (54 × 2 chains)
18Registered chain definitions

Nova Plus Wallet is a browser self-custody wallet. Keys are generated in the page, encrypted with the user password (ethers JSON keystore / scrypt), and stored only in localStorage. The mnemonic is shown once and is not persisted. Signing stays in memory after unlock.

The product surface is send, receive, swap, bridge, token catalog, and settings. NovaONE (chain 22016) and NRW World (33001) are default partner chains. Their catalogs are tokenized onto Nova settlement-meta (m2) liquidity. Local ERC-20 balanceOf on those chains is only the wrapped-bridge USDC. ALLTRA and Anaka contract addresses are canonical tokenized references, not copied onto the wrong chain.

Swap on 22016/33001 uses the Nova Bank API (HTTPS host allowlist) with a CoinGecko + peg mid fallback. Public EVM chains use 1inch v6 when VITE_1INCH_API_KEY is set. CSS class names still use the historical signet-* prefix; the product name is Nova Plus Wallet. Signet is not this product.

4. Architecture

The app is a static SPA. There is no Nova Plus Wallet backend. The browser talks to:

  • Public HTTPS RPCs listed on each chain (NovaONE / NRW via novabank.uk plus Railway fallbacks).
  • Nova Bank API /api/v1 (novabank.uk, then Railway) for settlement-meta status and quotes.
  • CoinGecko simple price for USD where tokens declare coingeckoId.
  • 1inch swap API on public EVM, only if an API key is built in.
  • Optional chainid.network world-chain list for extra public networks.

Layering

9. Custody and security

Source: src/lib/keystore.ts.

  • Create: Wallet.createRandom() (BIP-39).
  • Import: 12/24-word phrase or 32-byte hex private key.
  • Persist: wallet.encrypt(password) → signet.keystore.v1. Password minimum 8 characters.
  • Metadata: address, createdAt, accountType in signet.meta.v1.
  • Unlock: Wallet.fromEncryptedJson; signer held in React context only.
  • Auto-lock: AutoLockMonitor clears the in-memory signer after idle.
Institutional gate. src/lib/institutionalGate.ts compares a passphrase to SHA-256(VITE_INSTITUTIONAL_GATE) in the client. The file documents that this is not server-side authorization. Private-banking Anaka layers stay hidden until the session flag is set.

Nova API fetches in src/lib/nova-api.ts allow only HTTPS hosts: novabank.uk, www, Railway production, plus a build-time VITE_NOVA_API_URL host. Relative /api/v1 is allowed only on those same-origin hosts. This is the SSRF control for settlement quotes.

10. Balances, prices, and lists

useTokenBalances walks enabled reachable chains. For each chain it tries RPC URLs in order until one answers. It reads native balance and ERC-20 balanceOf only for tokens with a local address and standard === "erc20" (plus curated public lists / user-added tokens). Timeout 8s per RPC ping.

USD: token usd peg → CoinGecko id → oracle map in src/lib/prices.ts (60s cache). Public chain token lists: Uniswap, PancakeSwap, and other remote lists in tokenlist.ts, cached 24h. User tokens: usertokens.ts. Hidden tokens: prefs.

11. Swap: settlement-meta and 1inch

11.1 NovaONE / NRW (settlement-meta)

If the selected swap chain is 22016 or 33001, SwapPage renders MetaSettlementSwap.

  • Status: GET chain status, GET /swap/status, GET routers, NRW hub when on 33001. Probe API bases until /chains/nova-one returns JSON.
  • Pairs: src/lib/nova-one-markets.ts builds Binance-style symbols (e.g. USDC+NOVA → USDCNOVA). SELL if from is base; BUY if from is quote.
  • Quote: POST /chains/nova-one/markets/quote. Parse price, cummulativeQuoteQty / amountOut.
  • Fallback: USD cross via pegs + CoinGecko, 30 bps haircut, labelled settlement-mid. Used when quote POSTs 503 (observed on Railway hub/quote in August 2026).
  • Execute: this wallet does not submit settlement ledger orders. Copy states ledger execute stays on Nova Bank API.

11.2 Public EVM (1inch)

src/lib/swap/oneinch.ts — v6 quote + swap tx. Mesh chain IDs including 22016 and 33001 are in the unsupported set so 1inch is never faked there. globalSwap.ts can point at an in-app global swap URL for mesh chains; NovaONE/NRW UI prefers settlement-meta.

CORS: GitHub Pages calling Railway may be blocked. Production on novabank.uk should use same-origin /api/v1.

12. Bridge

Module src/lib/bridge/: constants, ABIs, route table, token map, history in localStorage, execute.ts (approve + lock/burn via ethers). UI: Bridge page, panel, review modal, history. Hub/spoke/vault addresses come from the registry — CONFIRM markers must not be guessed. This is separate from settlement-meta tokenization.
